Ledgerline for Android can now update itself.

- Settings has a new Updates card. "Check for updates" looks for a newer version on GitHub, shows what is new and downloads it only when you tap Download. The file is checked against the release and against Ledgerline's signing key before Android is asked to install it.
- "Check for updates automatically" looks once a day when the app opens. Turn it off in Settings if you would rather press the button. Nothing about you is sent.
- A notice on Home and More says when a newer version is out. The X hides it for that version.
- Settings, a theme choice (Light, Dark or System) and typing amounts from the cents.
- Searchable Category and Tag pickers, and an expense or income needs a category, as on the web.
- Transactions filters like the web's, working offline, with a setting for how long they stay.
