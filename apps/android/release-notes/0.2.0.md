Ledgerline on your phone has a new, calmer look. Every screen was redesigned with fewer words, one teal accent, and light, dark and system themes.

- Home, Transactions, Budgets, Insights, More, Clients, Loans, Categories and Settings all follow the same design: a top bar, grouped cards, one main action per screen, and smaller type that stays readable at the largest text size.
- Transactions has a search box with a Filters button. Filters open in a sheet. Both halves of a transfer show as one row, and days that came out ahead show a plus sign.
- Budgets: set a limit on any category, change it or remove it, with the amount spent shown next to it. Insights has a Net worth card.
- Categories opens as one card you expand: tap a group to see its subcategories. Adding and editing happen in a sheet, and you can pull down to refresh.
- Add transaction has a new layout: a big amount, the type at the top, and one card for payee, account, category and date. A new Pending switch keeps an entry out of your balance until it clears. It is off by default, so entries save as cleared as before. Pick an account, category or tag in a list that has a search box when there are many.
- Sign-in, the server address, the lock screen and Updates use the same look. Long explanations are now one short sentence.

No server update is needed. If you use the in-app update, Settings, Updates shows this version.
