A fix for being signed out when you did nothing wrong.

- If the app was locked for a while, it could tell you the session had expired and ask for your password and code again. While the app is locked it now sends nothing to the server, so your saved sign-in is kept.
- On a phone used by two people, the second person could briefly see the first person's figures after signing in. Home, Budgets, Insights, Clients and Loans now show a loading state until their own figures arrive.

No server update is needed. If you use the in-app update, Settings, Updates shows this version.
