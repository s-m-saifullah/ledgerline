- **2026-11-12:** Server: **the API survives a lost database connection, looks the session up once per request, and logs why four background steps failed** (merged as #261; tagged `v0.7.2` on `main`'s merge of it after `main`'s own check passed; release run 43176186637 passed its checks (scope, unit, three browser shards, Android) and built the images, and its deploy waits for the owner's approval in the protected `production` environment, so the release is not live yet; no migration, API contract unchanged at 0.1.55). **The crash:** when PostgreSQL restarted or dropped a connection, `pg` emitted `error` on the connection itself; the pool listens only for idle connections and removes its listener while a request uses one, so a connection lost in use, or ended by the server for sitting idle in a transaction, ended the whole API process.
